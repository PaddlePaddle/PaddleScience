## 1. Background Introduction

The Laplace equation is named after the French mathematician Laplace who first proposed it. This equation has important applications in many fields, such as electromagnetism, astronomy, and fluid mechanics. In practical applications, the solution of the Laplace equation is often a complex mathematical problem. For some practical problems with specific boundary conditions and initial conditions, specific numerical methods (such as finite element method, finite difference method, etc.) can be used to solve the Laplace equation. For some complex problems, more advanced numerical methods or high-performance computers may be needed for calculation.

This case solves the 2D form of the Laplace equation through deep learning.

## 2. Problem Definition

Laplace equation (2D form):

$$
\dfrac{\partial^{2} u}{\partial x^{2}} + \dfrac{\partial^{2} u}{\partial y^{2}} = 0, x \in (0, 1), y \in (0, 1)
$$

### 3.1 Model Construction

In the 2D-Laplace problem, each known coordinate point $(x, y)$ has a corresponding unknown quantity $u$ to be solved.
Here we use a relatively simple MLP (Multilayer Perceptron) to represent the mapping function $f: \mathbb{R}^2 \to \mathbb{R}^1$ from $(x, y)$ to $(u)$, that is:

$$
u = f(x, y)
$$

The first parameter of `InteriorConstraint` is the equation expression, used to describe how to calculate the constraint target. Here fill in `equation["laplace"].equations` instantiated in section [3.2 Equation Construction](#32);

The second parameter is the target value of the constraint variable. In this problem, we hope that the result `laplace` generated by the Laplace equation is optimized to 0, so set all its target values to 0;

The third parameter is the computational domain where the constraint equation acts. Here fill in `geom["rect"]` instantiated in section [3.3 Computational Domain Construction](#33);

The fourth parameter is the sampling configuration on the computational domain. Here we use full data points for training, so the `dataset` field is set to "IterableNamedArrayDataset" and `iters_per_epoch` is also set to 1, and the sampling point number `batch_size` is set to 10201 (representing a 99x99 equally spaced grid plus 400 boundary points);

The fifth parameter is the loss function. Here we choose the commonly used MSE function, and `reduction` is set to `"sum"`, which means we will sum the loss terms generated by all data points participating in the calculation;

The sixth parameter is to choose whether to perform equally spaced sampling on the computational domain. Here we choose to enable equally spaced sampling, so that training points can be evenly distributed on the computational domain, which is conducive to training convergence;

The seventh parameter is the name of the constraint condition. We need to name each constraint condition for subsequent indexing. Here we name it "EQ".
